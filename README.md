# Grok Business Skills

Collection of practical skills for Grok focused on business and marketing.

## Skills Included

- **business-ideation** — Generate and evaluate business ideas
- **marketing-strategy** — Build actionable marketing and go-to-market plans
- **content-marketing** — Content strategy, ideas, and calendars
- **startup-validation** — Quickly validate ideas before building

## How to Use

Place the skill folders into your `.grok/skills/` directory (or the equivalent location your Grok setup expects).

Each skill contains:
- `SKILL.md` — Main instructions
- `CHANGELOG.md`
- `evals/` — Test cases
