# Business Ideation

Generate high-quality business ideas and refine them systematically.

## Workflow

1. Clarify the user's constraints: budget, skills, time, location, preferred industry, risk tolerance.
2. Identify 3-5 promising opportunity areas based on:
   - Current trends (AI, health, sustainability, remote work, local services)
   - Pain points the user experiences or observes
   - Underserved markets
3. For each idea, provide:
   - One-sentence pitch
   - Target customer
   - Core value proposition
   - Rough revenue model
   - Estimated startup cost (low/medium/high)
   - Key risks
4. Score ideas on a simple 1-5 scale for: market size potential, competition intensity, execution difficulty, personal fit.
5. Recommend the top 1-2 ideas and explain why.
6. Suggest next validation steps.

## Idea Quality Checklist

- Solves a real, frequent pain point
- Customer can pay (or there is a clear monetization path)
- Not easily copied by a big player overnight
- Can be started with the user's available resources
- Has a clear path to first revenue

## Output Format

Always present ideas in a clean table or numbered list with the fields above. End with recommended next actions.
